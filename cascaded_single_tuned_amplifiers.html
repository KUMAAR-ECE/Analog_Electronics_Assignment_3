1. Introduction

A single-tuned amplifier uses a parallel LC tank as its collector (or drain) load. The tank is resonant at f0 = 1/(2π√(LC)), where its impedance is purely resistive and largest (Rp), so gain peaks at f0 and falls on either side. Cascading means connecting n identical stages in series, all tuned to the same f0 (synchronous tuning).

One stage gives limited gain and limited selectivity. Cascading multiplies gain and steepens the skirts, which is why IF strips and receiver front ends use several stages.

Prerequisites: parallel resonance, Q factor, bandwidth, small-signal BJT/FET model (gm, ro), the dB scale.

3. Working principle

  1. DC vs AC. The inductor is a near-short at DC, so the bias sets the Q-point. For signals the collector load is the tank impedance Z(jω).
  2. Single-stage gain. At resonance Z = Rp (= Qω0L), so A0 = −gmReff with Reff = Rp || ro || Rin,next. Away from f0, |Z| falls and so does gain.
  3. Cascading. Gains multiply (dB gains add). Each stage attenuates off-resonance signals again, so the combined curve is narrower and steeper.
  4. Trade-off. The gain-bandwidth product of the stage is roughly fixed. Adding stages buys gain and selectivity at the cost of bandwidth.
  5. Loading. The next stage’s input resistance (and ro) is in parallel with Rp. This lowers loaded Q, widens each stage, and its input capacitance adds to C and detunes f0.
  6. Feedback and stability. Cμ (Cbc) couples output to input (Miller effect). With high gain and an inductive source or load, this can cause oscillation. Remedies: lower gain per stage, neutralization, cascode, mismatched/tapped coupling.
  7. Stagger tuning. Tuning stages to slightly different frequencies gives a wider, flatter band at the cost of lower peak gain.

Advantages: high gain and selectivity at RF/IF; narrowband noise rejection. Limitations: bandwidth shrinks, alignment is needed, temperature drift detunes, risk of oscillation, inductors are bulky.

Misconceptions. (1) “Cascading increases bandwidth” is wrong for synchronous tuning; it reduces it. (2) “dB gains multiply” is wrong; dB gains add and linear gains multiply. (3) Increasing the number of stages does not reduce f0; it changes BW only.

5. Equations and derivations

Assumptions: identical stages, narrowband (Q > ~10, f near f0), negligible inter-stage interaction.

Resonance and Q

f0 = 1/(2π√(LC));   Q = Rp/(ω0L) = ω0CRp;   Z(f0) = Rp

Admittance Y = 1/Rp + jωC + 1/(jωL) has zero imaginary part when ω2LC = 1. Units: f in Hz, L in H, C in F, R in Ω.

Single-stage gain

Y = (1/Rp)[1 + jRp(ωC − 1/ωL)] = (1/Rp)[1 + jQ(ω/ω0 − ω0/ω)], so

A(jω) = A0 / [1 + jQ(f/f0 − f0/f)]  ≈  A0/(1 + j2Qδ),   δ = (f−f0)/f0

For small δ, f/f0 − f0/f ≈ 2δ. The magnitude is |A| = A0/√(1+(2Qδ)2). The −3 dB points are at 2Qδ = ±1, so BW1 = f0/Q (also = 1/(2πReffC)).

n identical stages

|Atotal| = A0n / (1 + (2Qδ)2)n/2;   dBtotal = n × dB1

Set the ratio to 1/√2: (1+x2)n/2 = 21/2 ⇒ x2 = 21/n − 1, with x = 2Qδ = 2Q(f−f0)/f0. Edge-to-edge BWn = 2δf0 = (f0/Q)x:

BWn = BW1√(21/n − 1);   Qn = f0/BWn = Q/√(21/n − 1)

Limit: n = 1 gives 1; as n grows, factor ≈ √(ln2/n) → 0. Physical meaning: each stage adds its own roll-off, so the product falls below 1/√2 sooner.

Loading

Reff = Rp || ro || Rin,next;   QL = Reff/(ω0L) = ω0CReff;   BW1 = f0/QL

Stagger-tuned pair (maximally flat)

Two stages centred at x = ±a: |A|2 ∝ 1/[(1+(x−a)2)(1+(x+a)2)] = 1/[(1+a2)2 + 2(1−a2)x2 + x4]. The x2 term vanishes for a = 1 (maximal flatness), giving |A| ∝ 1/√(4+x4). Normalised, the −3 dB point is x4 = 4, x = √2, so BW = √2·BW1 with centres at f0 ± BW1/2. At f0 each stage sits at x = ±1 from its own centre (−3 dB each), so the pair's peak gain is 6 dB below a synchronous pair of equal A0.

dB

dB = 20·log10|A|

7. Solved problems

P1 (Easy). L = 10 µH, C = 100 pF, Rp = 20 kΩ. Find f0, Q, BW.
f0 = 1/(2π√(10×10−6×100×10−12)) = 1/(2π×3.162×10−8) ≈ 5.03 MHz. ω0L = 3.162×107×10−5 = 316.2 Ω; Q = 20000/316.2 = 63.25; BW = 5.03 MHz/63.25 = 79.6 kHz (check: 1/(2πRpC) = 79.58 kHz). A high-Q tank is narrow: about 1.6% fractional bandwidth.
P2 (Moderate). BW1 = 100 kHz; find BW for n = 3 synchronous stages.
Factor = √(21/3−1) = √0.2599 = 0.5098, so BW3 = 50.98 kHz. The cascade is about half as wide as one stage.
P3 (Moderate/Difficult). IF at 10.7 MHz, BW1 = 400 kHz, each stage 20 dB. Overall BW must be ≤ 160 kHz. How many stages? Total gain?
Need factor ≤ 160/400 = 0.40. n = 4: 0.4350 → 174 kHz (too wide). n = 5: 0.3856 → 154.2 kHz (OK). Total gain = 5×20 = 100 dB (105 linear). Cascade Q5 = 10.7 MHz/154.2 kHz = 69.4. Real designs also check stability at 100 dB.
P4 (GATE-style, original). A stage has gm = 10 mS, L = 253.3 µH, C = 100 pF, Rp = 40 kΩ, loaded by a following Rin = 40 kΩ (neglect ro). Two identical stages are cascaded. Find f0, per-stage gain in dB, and overall BW and gain.
f0 = 1/(2π√(253.3µ×100p)) ≈ 1.000 MHz. Reff = 40k||40k = 20 kΩ. |A0| = 10 mS × 20 kΩ = 200 → 46.02 dB. BW1 = 1/(2π×20k×100p) = 79.58 kHz; BW2 = 79.58×0.6436 = 51.2 kHz. Overall gain = 2002 = 40,000 → 92.04 dB. Loading halved Q (unloaded Q = 25.1, loaded 12.6) and doubled BW1.
Shortcuts: add dB gains; BW factors from the table (0.644, 0.510, 0.435, 0.386); BW is independent of L when Reff and C are fixed.

9. Interview questions

1. Why does bandwidth shrink when you cascade tuned stages?

Each stage multiplies the response, so the product reaches 1/√2 closer to f0. BWn = BW1√(21/n−1). Follow-up: what about gain-bandwidth? Gain rises, BW falls.

2. How do you get wide bandwidth and high gain together?

Stagger tuning (or double-tuned stages, or a ceramic/SAW filter plus a wideband gain block). A maximally flat stagger pair gives √2·BW1 with offsets of ±BW1/2.

3. How does loading affect Q?

Reff = Rp||ro||Rin lowers QL and gain and widens BW. Remedy: tap the tank or use a transformer for impedance matching.

4. Why can tuned amplifiers oscillate?

Feedback through Cbc from collector tank to base. With high gain and the right phase at some frequency, the loop gain reaches 1. Fix with neutralization, cascode, lower gain, shielding and good layout.

5. How do you align a multi-stage IF amplifier on the bench?

Inject a signal at f0 at low level (avoid AGC action), tune from the last stage toward the first for maximum output, repeat, then sweep to verify centre and bandwidth. Keep the probe load small.

6. Why might a simulator’s AC sweep differ from theory?

Loading, transistor capacitances, finite ro, tank resistance, bias point changes and the narrowband approximation all shift f0, Q and gain.

7. A stage peaks at the wrong frequency after cascading. Why?

The next stage’s input capacitance adds to C, lowering f0. Re-tune or reduce the tank C accordingly.

8. Do dB gains multiply?

No, they add. Linear gains multiply.

9. Synchronous vs stagger tuning: trade-offs?

Synchronous: highest gain, narrowest BW, easiest alignment logic but steeper peak. Stagger: wider flatter band, lower peak gain, more careful alignment.

10. What drift affects tuned stages in production?

Temperature drift of L and C (ferrite cores), transistor capacitance changes with bias, and aging. Mitigate with NP0 capacitors, stable cores, temperature testing and crystal/ceramic filters.

Industry perspective: Modern receivers often use a ceramic or crystal filter for selectivity and a few lightly tuned or wideband stages for gain, but the same shrinkage and stability reasoning applies in alignment, validation and RF test.

10. Applications

  • IF strips: 455 kHz (AM) and 10.7 MHz (FM) superheterodyne receivers, plus TV IF.
  • RF front ends and narrowband receivers; wireless links needing channel selection.
  • Design issues: alignment, temperature drift, stability, neutralization, ceramic/crystal filters in modern designs, and testing under AGC.
  • Roles: RF design, analog design, hardware validation, test engineering, R&D.
